## Keyword glossary

### Commercial and pipeline

- **Pipeline:** Open potential business; not revenue or achievement.
- **Total open opportunity:** Direct plus distribution open value.
- **Direct / Altera Opportunity:** Opportunity directly covered by Altera.
- **Channel / Disti:** Distributor-led Channel Opportunity (DR).
- **Source row/product line:** One product record within an opportunity.
- **Distinct opportunity:** Unique Opportunity ID after product-line consolidation.
- **Qualified opportunity:** Named customer/use case, value, sponsor, decision path and next action.
- **DWIN:** Evidence-backed design win.
- **Gap closure:** Actions and value required to reach target.
- **Market share:** Altera content/value divided by total addressable customer content; requires a baseline.

### Stages

- **Identify:** Early use case; qualification incomplete.
- **Define:** Architecture, device fit and evaluation plan being established.
- **Develop:** Implementation and technical validation active.
- **Design:** Customer selection/design evidence substantially advanced.
- **Stage-exit evidence:** Objective proof required to move the CRM stage.

### Customer engagement

- **Workshop:** Structured architecture or solution session.
- **Demo:** Repeatable demonstration of a known solution.
- **PoC/evaluation:** Customer-specific technical validation against agreed success criteria.
- **Benchmark:** Measured latency, throughput, power, accuracy, resources, BOM or engineering effort.
- **48-hour follow-up:** Document outcome, owner and next action within two working days.

### Robotics and industrial

- **ROS 2:** Robot Operating System 2 middleware/framework.
- **AMR:** Autonomous Mobile Robot.
- **Sense–process–act:** Sensor ingestion, computation/decision and deterministic control.
- **Drive-on-Chip:** Integrated FPGA motor-control solution.
- **PLC:** Programmable Logic Controller.
- **TSN:** Time-Sensitive Networking for deterministic Ethernet.
- **IT/OT convergence:** Integration of enterprise/data systems with operational control.
- **Functional safety / FuSa:** Safety lifecycle and architecture supporting standards such as IEC 61508/ISO 13849.
- **Deterministic control:** Predictable bounded latency and low jitter.

### Vision and AI

- **Holoscan:** NVIDIA sensor-processing/AI platform integrated through Altera FPGA reference designs.
- **Hololink:** NVIDIA sensor bridge communication technology.
- **MIPI CSI-2 / D-PHY:** Camera sensor interface and physical layer.
- **SLVS-EC:** High-speed scalable low-voltage camera interface.
- **GigE Vision:** Ethernet-based machine-vision transport.
- **VVP Suite:** Altera Video and Vision Processing Suite.
- **FPGA AI Suite:** Altera AI inference development software.
- **ResNet-50:** Standard convolutional neural-network model used for inference validation.
- **ISP:** Image Signal Processor/pipeline.
- **Ingest–ISP–inference–output:** Complete vision data path.
- **CoE/RDMA:** Converged Ethernet / Remote Direct Memory Access.

### Tools, devices and board support

- **Quartus:** Altera FPGA design software.
- **SignalTap:** Embedded logic analyzer.
- **Platform Designer:** Altera system-integration tool.
- **PTA:** Power and Thermal Analyzer.
- **SOF:** SRAM Object File used to configure an FPGA.
- **BSP:** Board Support Package.
- **OPN:** Orderable Part Number.
- **HPS:** Hard Processor System.
- **UART:** Universal Asynchronous Receiver/Transmitter.
- **GTS bank:** Agilex transceiver bank.
- **LPDDR5:** Low-power DDR5 memory.
- **MSI:** PCIe Message Signaled Interrupt.
- **EPCQ128:** Configuration flash device.
- **RPD:** Raw Programming Data file.
- **BOM:** Bill of Materials.

### Competitive terms

- **AMD Kria/KR260:** AMD SOM and robotics development platform.
- **Kria Robotics Stack:** AMD ROS 2-centric acceleration stack.
- **Vitis AI:** AMD AI deployment platform.
- **VVAS:** AMD Vitis Video Analytics SDK.
- **Versal AI Edge:** AMD adaptive SoC family with AI Engines.
- **Competitive benchmark:** Like-for-like workload comparison using the same model, precision, interfaces, clocks, power method and tool version.
